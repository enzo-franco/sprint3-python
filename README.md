# 📚 Jovi Study Mode

> Ferramenta em Python para estudantes organizarem fotos de materiais didáticos — lousa, cadernos e livros — e recuperá-las rapidamente por matéria.

--

## 🎯 Sobre o Projeto

No dia a dia acadêmico, é comum tirar fotos de quadros e anotações — mas essas imagens acabam se perdendo na galeria do celular. O **Jovi Study Mode** resolve esse problema centralizando e classificando esses registros por matéria, otimizando o tempo de estudo e trazendo mais organização para o aprendizado.

O objetivo é oferecer uma ferramenta **simples, intuitiva e estruturada** para que estudantes consigam recuperar rapidamente qualquer foto de material didático, categorizada por disciplinas.

---

## ⚙️ Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| **Menu Principal Interativo** | Navegação contínua: o programa permanece em execução e retorna às opções principais após cada ação. |
| **Adicionar Foto** | Cadastra o nome de uma foto e a vincula a uma matéria (Matemática, História, Biologia ou Física), com validação rigorosa de entrada. Os dados são salvos em estrutura de **Dicionário**, armazenados em uma **Lista** principal. |
| **Ver Galeria** | Exibe todas as fotos cadastradas e suas respectivas matérias em uma interface limpa. Se a lista estiver vazia, o sistema avisa o usuário. |
| **Identificar Matéria** | Recebe um texto extraído da imagem (simulação) e, por análise de palavras-chave em minúsculas (ex.: `"equação"`, `"célula"`), identifica logicamente a matéria correspondente. |

---

## 🛠️ Tecnologias

- **Python 3** — linguagem única do projeto
- Estruturas de dados nativas: **Dicionários** e **Listas**
- Código 100% modularizado em **sub-rotinas (funções)**
